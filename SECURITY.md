# Security Policy

## Supported Versions

Currently, VoxTrade is under active development and has not yet undergone a formal security audit. Use at your own risk.

| Version | Supported          |
| ------- | ------------------ |
| < 1.0.0 | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within VoxTrade, please DO NOT disclose it publicly.

Instead, please send an email to the maintainers at **security@voxxtrade.network** (or open a Draft Security Advisory on GitHub).

We will respond within 48 hours to acknowledge receipt of the vulnerability and outline the remediation plan.
