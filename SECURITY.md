# Security Policy

## Supported Versions
Only the latest branch (`main`) is currently receiving security updates.

## Reporting a Vulnerability
If you discover a vulnerability in the `agent_treasury` spending limits, the `x402_escrow` HTLC timeout boundaries, or any cross-contract call logic, please do NOT open a public issue. 

Email the core team directly. We commit to a 24-hour response time for all smart contract vulnerabilities.
